## 拆分时处理的几处特殊情况

1. **《话说中庸》原先并不独立成册。** 它夹在《论语别裁》的版权页区间里（原文件第 8913～11662 行），自带一套「编者的话 / 出版说明 / 前言 / 目录」，但全书没有单独的 CIP 版权页，所以按 CIP 切分时会被并入《论语别裁》。现已单独拆出为第 02 册，其中《附录一　话说中庸》《附录二　南怀瑾先生年谱（简谱）》一并保留在该文件内。
2. **《历史的经验》的版权页在正文之后。** 全书其余 47 册都是「版权页在前」，只有它是「正文在前、版权页在后」，且它前面紧跟着《药师经的济世观》结尾的书目广告；按 CIP 切分会把它切成只剩 50 行的空壳，因此改为从该广告块之后起算。
3. **每册结尾的「东方出版社南怀瑾作品」书目广告**（共 33 处）与版权页、原书目录块一并删除，不重复出现在各册。
4. **按你的选择剥离了出版方文字**：版权页/CIP 数据页、编者的话、出版说明、编辑说明、整理说明、以及「封面／版权信息／扉页／插图」这类电子书导航项。南师自己的前言、自序、再版记言、校订版说明、附录、年谱等均作为正文保留。
5. **分册未合并**：《我说〈参同契〉》上中下、《维摩诘的花雨满天》上下、《列子臆说》上中下、《老子他说》初续合集都按原文件里的实际分册各出一个文件。

## 校对结果

- 原文件第 102 行至末尾共 69885 个非空行；拆分后 48 册的区间首尾相接，无重叠、无遗漏。
- 需要进入正文的行 61435 行，其中 61,421 行在成书中逐行核对可找到；字面未匹配的 14 行已逐条核实，没有丢内容：其中 11 行是《人生的起点和终站》版权页里的印次／开本／字数／定价／发行电话等字段（本就应该删除），另外 3 行是被电子书粘连的章题（如「第三讲」与其下小标题并成一行），已拆成两级标题，故不再字面相同。
- 主动删除的出版方内容 8450 行（原目录块 5,856 ＋ 版权页 1,075 ＋ 书目广告 793 ＋ 编者的话 369 ＋ 出版说明 330 ＋ 编辑说明 27）。
- 成书中不再出现任何版权页字段（ISBN、定价、印刷、版次、发行电话等 20 项关键字全部检索为空）。
- 48 个文件均只有一个 H1；无三级以上连续空行；无「星号分隔线被当成标题」的假标题。
- 标题层级分布：H2 1,460 ／ H3 2,966 ／ H4 1,149 ／ H5 102。

## 已知的小瑕疵

电子书导出的正文里有少量段落被硬回车截断（上段末字与下段首字本是一句）。转换时按「末行无句末标点且行数较长」做了缝合，最多连 3 次，仍有个别段落可能被拆开或误并；另有 7 册存在一次「标题层级跨级」（如 H2 直接到 H4），不影响阅读，需要可再调。
